# CONTABILANDIA COMPLETA

## Abrir el proyecto
1. Descarga y descomprime `CONTABILANDIA_COMPLETA.zip`.
2. Abre la carpeta `CONTABILANDIA_COMPLETA` en Visual Studio Code.
3. Abre `index.html` con Live Server (o abre el archivo directamente en un navegador).

## Contenido
- 10 mundos inspirados en el mapa de Contabilandia.
- 100 niveles: 10 por mundo.
- 1,000 preguntas de opción múltiple: 10 por nivel, tres opciones cada una.
- Cada nivel contiene definición, explicación paso a paso, ejemplo, orientación para reconocer el concepto y resumen.
- Cada respuesta muestra retroalimentación y un mensaje motivacional cuando es incorrecta.
- Sistema de estrellas: 100% = 3; 50–99% = 2; 25–49% = 1; menos de 25% = 0.
- Desbloqueo progresivo de mundos por estrellas.
- Guardado local del progreso en el navegador.

## Base documental
Los conceptos y definiciones principales se organizaron a partir de las tarjetas del PDF `TARJETAS DE PREGUNTAS (1).pdf` (25 páginas). Las explicaciones y ejemplos se ampliaron didácticamente para enseñar los conceptos. Las preguntas se generan a partir del contenido de cada lección. Cuando una tarjeta solo aporta una definición breve, la ampliación se mantiene en el alcance de esa definición y no pretende sustituir una norma, legislación o manual completo.

## Nota
El progreso se guarda en el navegador y en el dispositivo donde se juega. Si borras los datos del navegador, el progreso local podría perderse.
